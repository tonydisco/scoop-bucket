# scoop-bucket

Scoop bucket for [tonydisco/claude-usage](https://github.com/tonydisco/claude-usage).

```powershell
scoop bucket add tonydisco https://github.com/tonydisco/scoop-bucket
scoop install claude-usage
```

Manifests in [`bucket/`](bucket/) are pushed automatically by [goreleaser](https://goreleaser.com/) on every tagged release of the upstream repo.
